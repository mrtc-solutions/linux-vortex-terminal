# Changelog

## 0.1.0 — 2026-08-25

- Established Linux Vortex Terminal repository foundation.
- Added dependency-free Python sidecar, deterministic planner, typed plans,
  approval tokens, real shell-free execution, redaction, audit chain, and CLI.
- Added Electron-ready local desktop renderer with Vortex visual identity,
  engagements, tool health, activity, reports, settings, and post-execution
  analysis.
- Added threat model, compatibility contract, exit code contract, tests, and
  implementation report.

This is a vertical slice, not a 1.0 security scanner or penetration-testing
automation release. See the capability matrix in `README.md`.
