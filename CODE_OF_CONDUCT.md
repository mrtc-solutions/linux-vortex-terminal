# Code of Conduct

We are committed to a respectful, inclusive, and technically rigorous project.
Participants must be constructive, assume good faith, and avoid harassment,
discrimination, doxxing, threats, or publishing private information.

Security discussions must stay within authorized, scoped testing. Do not post
credentials, live target data, weaponized exploit chains, or unredacted logs.
Maintainers may remove content or suspend participation for behavior that
threatens people, project users, or the safety boundary. Report conduct concerns
privately to the repository maintainers.
