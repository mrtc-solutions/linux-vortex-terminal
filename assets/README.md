# Vortex artwork provenance

`hooded-researcher.svg` is an original, project-owned abstract vector illustration created for Linux Vortex Terminal. It depicts a privacy-preserving researcher without a real person, live surveillance, system compromise, or criminal conduct. It is a decorative renderer asset only and is never loaded by the Python execution authority.

`icons/vortex.svg` and `icons/vortex-*.png` are the application icons used by the Linux `.desktop` entry (`Icon=vortex`), the `.deb` hicolor/pixmap install, and the Electron window (`npm start`). They are shipped as real files in the package; they are not generated at install time.
